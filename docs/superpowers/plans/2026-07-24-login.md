# Email+Password Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working login flow — a SvelteKit `/login` page (email + password) that authenticates against a real Postgres `users` table via a Spring Boot session-cookie login endpoint, with logout, and with the project's new audit-fields convention (`created_at`, `created_by`, `updated_at`, `updated_by`) established via a `BaseEntity` for every future table.

**Architecture:** Backend adds Flyway-managed migrations (`users` table + audit columns + one seeded dev user), a `BaseEntity`/JPA-auditing mechanism resolving the acting user from the HTTP session, and a session-cookie `AuthController` (`/api/login`, `/api/logout`) using `BCryptPasswordEncoder` — no full Spring Security. Frontend adds a small `fetch`-based API client and a Svelte 5 login form that calls it with `credentials: 'include'`.

**Tech Stack:** Spring Boot 4.1.0 (Java 21, Gradle), PostgreSQL, Flyway, `spring-security-crypto` (BCrypt only). SvelteKit (`adapter-node`, TypeScript, Svelte 5 runes mode forced).

## Global Constraints

- Java 21 / Spring Boot 4.1.0 / Gradle — package root `ee.tervisehull.backend`.
- Do not add `spring-boot-starter-security` — use `spring-security-crypto` only (no default filter chain/login page/CSRF).
- Every table gets four audit columns: `created_at`, `created_by`, `updated_at`, `updated_by` (`wiki/backend.md`, `CLAUDE.md`). Every JPA entity extends `BaseEntity`.
- `id` columns use `BIGINT GENERATED ALWAYS AS IDENTITY` (no `pgcrypto`/UUID dependency).
- `created_by`/`updated_by` are nullable, no FK constraint.
- Login/logout failure responses never distinguish "unknown email" from "wrong password" — same 401 + `"Invalid email or password"` for both.
- No signup endpoint, no password reset, no rate-limiting, no production `SameSite=None; Secure` cookie hardening — out of scope, tracked as open decisions in `wiki/roadmap.md`.
- Backend tests require a running Postgres: `docker compose up -d db` from repo root before running `./gradlew test` (matches the existing project pattern — there's no embedded/H2 test database).
- Frontend has no test runner configured; verification is `npm run check` (type-checking) plus manual browser testing.
- Svelte components use runes mode (`$state`, `$props`, `onsubmit={...}` handlers), matching `frontend/src/routes/+layout.svelte`.

```java
package ee.tervisehull.backend.common;

import java.time.Instant;

import jakarta.persistence.Column;
import jakarta.persistence.EntityListeners;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.MappedSuperclass;

import org.springframework.data.annotation.CreatedBy;
import org.springframework.data.annotation.CreatedDate;
import org.springframework.data.annotation.LastModifiedBy;
import org.springframework.data.annotation.LastModifiedDate;
import org.springframework.data.jpa.domain.support.AuditingEntityListener;

@MappedSuperclass
@EntityListeners(AuditingEntityListener.class)
public abstract class BaseEntity {

	@Id
	@GeneratedValue(strategy = GenerationType.IDENTITY)
	private Long id;

	@CreatedDate
	@Column(name = "created_at", nullable = false, updatable = false)
	private Instant createdAt;

	@CreatedBy
	@Column(name = "created_by")
	private Long createdBy;

	@LastModifiedDate
	@Column(name = "updated_at", nullable = false)
	private Instant updatedAt;

	@LastModifiedBy
	@Column(name = "updated_by")
	private Long updatedBy;

	public Long getId() {
		return id;
	}

	public Instant getCreatedAt() {
		return createdAt;
	}

	public Long getCreatedBy() {
		return createdBy;
	}

	public Instant getUpdatedAt() {
		return updatedAt;
	}

	public Long getUpdatedBy() {
		return updatedBy;
	}
}
```

```java
package ee.tervisehull.backend.common;

import java.io.IOException;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import jakarta.servlet.http.HttpSession;

import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

@Component
public class CurrentUserFilter extends OncePerRequestFilter {

	private final CurrentUserHolder currentUserHolder;

	public CurrentUserFilter(CurrentUserHolder currentUserHolder) {
		this.currentUserHolder = currentUserHolder;
	}

	@Override
	protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain)
			throws ServletException, IOException {
		HttpSession session = request.getSession(false);
		if (session != null && session.getAttribute("userId") instanceof Long userId) {
			currentUserHolder.setUserId(userId);
		}
		filterChain.doFilter(request, response);
	}
}
```

```java
package ee.tervisehull.backend.auth;

import java.util.Map;
import java.util.Optional;

import ee.tervisehull.backend.user.User;
import ee.tervisehull.backend.user.UserRepository;

import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpSession;

import org.springframework.http.ResponseEntity;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api")
public class AuthController {

	private static final String INVALID_CREDENTIALS_MESSAGE = "Invalid email or password";

	private final UserRepository userRepository;
	private final BCryptPasswordEncoder passwordEncoder = new BCryptPasswordEncoder();

	public AuthController(UserRepository userRepository) {
		this.userRepository = userRepository;
	}

	@PostMapping("/login")
	public ResponseEntity<?> login(@RequestBody LoginRequest loginRequest, HttpServletRequest request) {
		Optional<User> user = userRepository.findByEmail(loginRequest.email());

		if (user.isEmpty() || !passwordEncoder.matches(loginRequest.password(), user.get().getPasswordHash())) {
			return ResponseEntity.status(401).body(Map.of("message", INVALID_CREDENTIALS_MESSAGE));
		}

		HttpSession session = request.getSession(true);
		session.setAttribute("userId", user.get().getId());

		return ResponseEntity.ok(new LoginResponse(user.get().getEmail()));
	}

	@PostMapping("/logout")
	public ResponseEntity<Void> logout(HttpServletRequest request) {
		HttpSession session = request.getSession(false);
		if (session != null) {
			session.invalidate();
		}
		return ResponseEntity.ok().build();
	}
}
```

- [ ] **Step 2: Write `src/lib/api.ts`**

Create `frontend/src/lib/api.ts`:

```typescript
import { env } from '$env/dynamic/public';

const API_URL = env.PUBLIC_API_URL ?? 'http://localhost:8080';

export interface LoginResult {
	email: string;
}

export class InvalidCredentialsError extends Error {
	constructor() {
		super('Invalid email or password');
	}
}

export async function login(email: string, password: string): Promise<LoginResult> {
	const response = await fetch(`${API_URL}/api/login`, {
		method: 'POST',
		headers: { 'Content-Type': 'application/json' },
		credentials: 'include',
		body: JSON.stringify({ email, password })
	});

	if (response.status === 401) {
		throw new InvalidCredentialsError();
	}

	if (!response.ok) {
		throw new Error('Something went wrong, try again');
	}

	return response.json();
}

export async function logout(): Promise<void> {
	await fetch(`${API_URL}/api/logout`, {
		method: 'POST',
		credentials: 'include'
	});
}
```

- [ ] **Step 1: Write the login page**

Create `frontend/src/routes/login/+page.svelte`:

```svelte
<script lang="ts">
	import { goto } from '$app/navigation';
	import { login, InvalidCredentialsError } from '$lib/api';

	let email = $state('');
	let password = $state('');
	let loading = $state(false);
	let errorMessage = $state('');

	async function handleSubmit(event: SubmitEvent) {
		event.preventDefault();
		errorMessage = '';
		loading = true;

		try {
			await login(email, password);
			await goto('/');
		} catch (error) {
			errorMessage =
				error instanceof InvalidCredentialsError
					? error.message
					: 'Something went wrong, try again';
		} finally {
			loading = false;
		}
	}
</script>

<form onsubmit={handleSubmit}>
	<h1>Log in</h1>

	<label for="email">Email</label>
	<input id="email" type="email" bind:value={email} required autocomplete="email" />

	<label for="password">Password</label>
	<input
		id="password"
		type="password"
		bind:value={password}
		required
		autocomplete="current-password"
	/>

	{#if errorMessage}
		<p role="alert">{errorMessage}</p>
	{/if}

	<button type="submit" disabled={loading}>
		{loading ? 'Logging in…' : 'Log in'}
	</button>
</form>
```
